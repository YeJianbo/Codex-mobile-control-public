# 配套 Local Console

此目录保存 Windows 发行包使用的 Local Console 0.12.11 组件，首次导入自本机已安装版本（2026-10-18）。`src` 为服务源码，`dist` 为实际交付的 Web 管理前端；依赖锁和 Node 校验清单随组件一起版本控制。前端当前以发行产物形式维护，此目录不包含其独立前端开发工程。公网连接表单支持生成和移除秘密路径；地址校验由 Gateway 统一处理。

账号、配对信息、安装路径和运行数据库不在此目录。Gateway 与 Android 的权威源码仍在仓库原目录。

`installer/build-release.py` 默认读取这里的组件内容。`--console-dir` 可显式选择另一份组件；`--console-runtime-dir` 只提供已安装的 npm 依赖和 Node 缓存。打包时逐项校验生产依赖版本以及 Node 文件完整性，不从安装目录覆盖本目录的源码或前端。

升级此组件时一起更新源码、前端、包元数据、依赖锁与 Node 清单，并核对管理桥接口。仓库提交由此能够确定所交付的组件内容；无需在项目中再复制 node_modules 和 Node 二进制。

## 字体

沿用基础样式原有的 Inter / Segoe UI / Microsoft YaHei 字体链、字号和字重。管理页面不再覆盖字体族，代码使用原有等宽字体。页面仅加载 `app.css` 与 `management.css`，不附加替换字体层或下载字库。

## 速度统计

活跃趋势的年度汇总只读取活跃事件，并复用现有覆盖索引；Token 日历仍由独立请求加载。打开活跃趋势不再同步统计全年工具调用和 Token 金额，其他统计视图保持原有计算口径。各执行器结果独立显示，不等待全部来源返回。外部执行器的 HTTP 查询和请求记录刷新共用原有后台扫描线程及来源缓存，不在 HTTP 主线程扫描会话文件。

2026-10-20：速度按模型、服务档位、思考强度、回复类型分组，进度说明与最终回复分开。原生历史是可见文本的整段平均速率估算，Fast 来自会话设置；工作台请求按上游服务档位记录，正文首字使用 firstTextMs。Web 折叠行的分组键与服务聚合维度一致。派生缓存新增维度后重建自身游标，原始会话历史保留。

## Credits 与订阅估算

Web 额度历史及「统计 → 配额」在额度曲线下方展示官方 `wham/usage` 返回的 Credits 余额及余额曲线。与额度共用账号、时间范围、刷新和历史响应，不再单独查询或设置时间；两张图的时间刻度一致。Android 账号额度也按额度数字、额度曲线、Credits 的顺序展示，共用顶部时间选择及时间轴。余额下降累计为区间已观测消耗，上升单列为余额增加；未采集的历史不补造。自动预热的只读探测更新当前值和曲线末点，不额外写入高频历史。余额无限、真实零余额与缺失数据分开处理。

订阅 5h / 7d 折合 Credits 是基于已观测请求的估算下限，不是官方公布的订阅总预算。采用 [Codex 官方 Credits 单价](https://learn.chatgpt.com/docs/pricing)，独立计算 Fast / Ultrafast 的订阅权重与购买 Credits 扣费倍率。按账号、套餐和重置周期隔离，至少两个区间、三个已计价请求、五个百分点变化才显示；否则显示「采集中」。未知模型或未知速度档位不估价，区间分别留出百分比舍入余量。

官方直连读取现有增量用量索引中的账号、官方窗口与余额元数据；本地路由在请求开始时记录计费账号。只有采样期间 Credits 未下降、官方窗口一致且能确认归属的请求用于订阅校准。同一会话的路由与原生观察不重复计入。旧事件没有元数据时保留未知，不为该功能全库重建或改用 API 反代。

## 中转配置

「模型 → 连接与中转」使用可搜索的供应商列表；添加、编辑共用弹窗，集中处理连接信息、模型拉取、多选、手动添加、显示名称与上下文设置。取消不提交，密钥留空保留已保存值，修改地址仍须提供对应的新密钥。连接方式与路由折叠展示，继续使用原有配置与校验。

独立前端模块为 `console-management-client.js`、`credit-history.js`、`relay-management.js` 和 `console-management-ui.css`；Gateway `/manage/` 复用这些资源和设备鉴权。
# 额度自动预热

Web 在「账号 → 额度历史」配置自动预热，Android 从「设置 → 自动预热」进入；Android 账号额度弹窗只展示额度和趋势。两端使用相同的常驻后台设置，支持独立选择 5 小时和 7 天窗口。默认选中 7 天，安装默认关闭。当前开发机已按用户要求开启 7 天。

开启后每 30 秒读取官方额度。确认重置且 Codex 空闲后，向官方发送一次只回复 OK 的最小请求；两个窗口同时重置会合并。已有正常请求使用新窗口时跳过，忙碌时等候，不向现有聊天插入消息，不调用工具。按账号持久化发送记录，结果不明或后台重启不重复发送。官方重置时间仍以官方返回为准。


## 逐条请求记录

Web 统计页点击「请求记录」；Android 详细统计选择「请求」。统一读取 Codex、Antigravity、Claude、ZCode、Grok、Hermes、DeepSeek、OpenCode 和本地路由的已有用量索引，分页不扫描原始会话。列表提供 Token、缓存、首字、耗时、速度、金额与请求／响应档位；只有合计的来源显示汇总次数。未记录的时间和速度显示 —，价格区分参考估算、原生估算、供应商实报和套餐包含。速度使用输出 Token 除以整个请求耗时。

本地路由的请求元数据保存到 request-records.sqlite，原滚动日志继续供原有统计使用。归档不记录提示词或正文。只有会话、模型、计量与邻近时间都吻合且双方唯一时，才合并原生与路由的重复观察。

## 模型与全部额度

Web 侧栏的「模型与额度」提供账号额度总览及原生模型能力目录；账号配置仍由原有「账号」页面管理。模型目录复用 Gateway 的 `/api/models?agents=all&partial=1`，按 Harness 分组，展示原始 ID、思考等级、默认等级、已知上下文和输入类型，不重新维护模型列表。没有提供的能力保留未知。

Android 侧栏保留当前助手的独立额度弹窗；「设置 → 全部额度」查看 Codex、Antigravity、Claude 的当前及已保存账号，可筛选全部／当前账号。其他 Harness 没有统一可读取的官方额度时显示能力缺口，不把 Token 用量或余额猜成订阅百分比。

两端先读取 `GET /api/quota-overview?catalog=1` 的来源名称、`supported` 和 `refreshable`，再独立加载支持的来源。该目录只返回能力元数据，不读取账号或查询官方额度；移动端通过 `/api/mobile-management/statistics/quotas?catalog=1` 使用同一目录。新增额度适配时，两端无需再各维护一份三来源名单。

AGY 查询失败保留上次成功的额度与原采集时间，标记「上次成功数据」；后续成功刷新会清除失败状态。Web 按账号及额度项复用 DOM，只更新有变化的字段，刷新时保留展开、焦点和滚动位置。Android 默认显示四项，展开后额度行直接进入外层惰性列表，不在单个大卡片内一次组合全部模型条目。

`GET /api/quota-overview?source=all|codex|agy|claude|…` 只读取本机账号元数据和已有额度记录。`POST /api/quota-overview/refresh` 提交按来源去重的后台查询，只刷新当前登录账号，复用官方额度读取和 AGY CLI 的只读 `/usage`；不切换账号或发模型消息。Web 和 Android 各来源独立加载，只有后台任务未结束时轮询；离页、切后台或断开时停止页面查询，后台读取可继续。原生身份读取短暂缓存并共享进行中的工作，避免轮询反复启动凭据进程。

Claude 总览按每个账号的历史归属读取，独立于账号页面选中了哪个账号；刷新失败保留上次成功记录及时间。AGY 的未保存登录在官方身份包含 subject 时使用该身份归属新样本，旧的无归属记录单独显示，不挂到当前账号。

逐条请求区分真实响应档位与原生会话设置。已观测的首字节、首输出、首字及首输出后耗时单独展示；原生输出流估算与整个请求计时使用不同标签。多请求合计记录不再显示为一条请求的速度或延迟。Android 请求页增加完整模型 ID 筛选，计价来源标签与 Web 一致。

## QQ / 微信助理入口

「新会话」默认可选「通用助理 · 不绑定项目」，无需先选工作目录。每个账号、联系人和聊天分别绑定独立会话；底层 Harness 所需的目录自动保存到网关数据目录的 assistant-workspaces 下，不在每次消息时新增项目。仍可选择已连接项目，修改设置只影响新会话，发送 /新会话 可重新开始。

QQ／微信助理通过本机 AGY CLI 调用 Gemini 3.8 Flash，使用 AGY 已登录账号和模型目录，不经过 Codex 或其 Gemini 中转。思考强度采用 AGY 目录默认值，当前为 medium；执行沿用 AGY 自动审批模式，不添加跳过权限参数。成功提交不再发送回执，仅在结束时回传答复。这一入口尚不提供自动选择其他 Harness 的调度工具。支持文字；图片、文件仍使用手机或电脑控制台。

旧会话不属于 AGY CLI 时，下一条新消息自动创建 AGY 会话并更新渠道绑定，复用原工作目录。原会话和消息记录保留，不迁移完整历史，不重发先前失败的消息；原任务仍在运行时等待其结束后再切换。AGY 的续聊、状态、结果和停止使用自身执行器与历史，底层禁止同一会话跨执行器的检查继续保留。

Android 主聊与侧聊均可在附件菜单选择「拍照」，调用系统相机拍摄完整照片。返回后进入原会话附件预览，由用户发送；取消拍摄或上传结束会清理临时照片。相机期间会话改变时不会将照片加到另一会话。

侧聊停止中会禁用重复点击；已空闲的停止请求按结束处理。重连以服务端快照恢复运行状态，读取过程中出现的新轮次事件优先于旧快照。操作错误只在状态区显示一次，历史中的重复“没有正在运行的任务”提示会移除；发送失败保留文字与附件。

## QQ 身份授权

QQ 私聊默认拒绝所有未授权发送者，旧的会话绑定不自动授予权限。在 QQ／微信管理页点击「生成绑定码」，用希望授权的 QQ 私聊机器人发送显示的 /绑定 命令。验证码十分钟内有效、只能使用一次，重新生成会废弃旧码；按官方消息事件的 OpenID 授权，每个机器人最多 8 个账号。网关只保存验证码摘要，不将绑定命令交给模型或写进会话。

任务提交、状态／结果／停止指令和结果回传都检查身份。「清除授权」撤销全部 QQ 访问与渠道绑定，原会话记录保留；更换 AppID 清除原身份授权。微信继续仅接受扫码登录的本人身份。机器人权限不会因消息文本或陌生人先发消息而扩大。
