# Android 0.6.143 / Gateway 0.6.54

桌面 Codex 崩溃重开后，历史中的 `task_started` 没有对应结束事件。网关原先直接将它解释为运行中，手机的发送、停止与队列因此继续受旧状态影响。

## 修复

- 对非网关持有的 Codex 运行状态，以 `thread/read` 的当前状态核对。后台为 idle 或 notLoaded 时保存已中断状态及结束事件；active 时保留运行状态，读取失败或未知状态不结束任务。
- 状态核对期间收到新轮次通知时保留新任务；并发读取只补充一次结束事件。会话正文、草稿、目标及原有队列保留，已有的异常结束后队列暂停规则继续生效。
- 恢复会话时，后台明确 idle 的旧 inProgress 记录不再加入当前轮次。停止已中断的旧任务返回当前状态，避免继续向已失效的轮次发送停止请求。
- 网关 0.6.54 已按现有更新流程部署。Android 生产代码没有变化，继续使用 0.6.143/code166；正式下载 APK 与该交付文件一致。

## 验证

- Node 271/271；网关 smoke 38/38；Web 53/53。新增真实网关协议 fixture 覆盖旧历史校正、网关重启后的恢复、停止旧任务和继续会话；并覆盖新轮次竞态、并发读取与断线保护。
- Android 隔离 fixture 1/1：以旧 running 状态打开会话，校正后正文和草稿保留，输入框可用。
- Android 正式网关只读检查 1/1：实际读取用户的旧会话，正文和恢复事件存在、运行占用解除、草稿保留；随后打开当前活跃任务，仍显示运行。没有发送模型请求，未安装实体手机。
- 正式网关 API 校正四个遗留任务；两次读取及侧栏状态一致。当前主线程保持 running，没有补充中断事件。68 个安装运行文件及 APK 下载与交付内容一致。
- 全量 Node 首次使用普通 Node 启动，退出码 1，`ERR_MODULE_NOT_FOUND` 指向 TypeScript 源文件的 .js 导入路径；使用项目的 `--import tsx` 后全部通过。首次日志保留。正式 Android 截图首次尝试从应用沙盒复制到共享目录报 `Permission denied`；改用 `adb exec-out run-as` 读取后取得并检查原始截图，未改动图片。
- Web 首次退出码 1：图片任务用例提前将短暂的发送空闲状态当作任务结束，处理记录随后重新归组折叠，导致展开后内容可见性断言超时 30 秒。用例改为先等待该轮最终回复，再检查结束状态和展开内容，重跑 53/53 通过；修正的是测试同步，Web 产品折叠行为沿用原实现。

此前 AGY、Claude、Grok 的真实 CLI、内置浏览器与 Android 续聊调试见 [0.6.143 验证](verification-0.6.143.md)。本次复用其 APK、JVM 181/181 和 lint 0 errors / 25 warnings 记录；不把旧验证当作本轮重跑。Claude/Grok 的公网开放范围仍待此前询问的用户答复，当前公网继续保持 Codex/AGY。
