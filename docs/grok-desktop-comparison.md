# Grok-Desktop 功能对照

2026-09-26，参考 AnRkey/Grok-Desktop 提交 `6af8d483430b8c01b8830f22a634069edf65c0ee`。本次为源码及仓库截图对照，未登录运行 Grok 服务。我们的状态按当前源码判断，不将功能存在等同于体验合格。

## 可确认的差异

| 功能 | Grok-Desktop | 我们的网页 / 原生 Android |
|---|---|---|
| 深浅主题、跟随系统 | Electron nativeTheme 同步外壳及网页 | 两端目前浅色，缺少完整主题切换 |
| 账户额度、重置时间 | 获取 Grok rate-limits，低余额着色、定时刷新 | 两端缺少账户额度面板；需要接 Codex 数据，不能搬 Grok 接口 |
| 应用内多标签 | 每个标签独立 webview，快捷键切换 | 有会话列表与切换，没有应用内多标签；网页可用浏览器多标签 |
| 语音模式 | 放行媒体能力，由 grok.com 实现语音产品 | 两端没有专门语音输入/对话；手机键盘听写不算本应用功能 |
| 桌面窗口置顶 | Electron / wmctrl | 没有对应自有桌面聊天窗口；不是网页或安卓的直接缺项 |
| 快捷键 | 新标签、切换、刷新、关于 | 网页已有新会话、搜索、保存、关闭；缺会话快速轮换 |
| 登录与持久会话 | Grok、Google、Apple OAuth 和持久 cookie | 电脑网关配对、保存凭据、重连；认证对象不同 |
| 图片另存、链接打开 | Electron 上下文菜单 | 网页附件预览下载；安卓文件授权下载交给系统查看器。安卓图片专门预览/保存交互仍需完善 |
| 富文本、公式、代码、图片 | 主体由远程 grok.com 提供，仓库未实现其渲染器 | 网页 Markdown / KaTeX；安卓 Markwon / JLaTeXMath，当前开发版含代码复制与宽表横滚 |
| 执行进度、审批、持久消息队列 | 开源外壳中未找到独立实现，不能据此断言 grok.com 没有 | 我们已有，仍需以运行中、断线、跨端场景检查体验 |
| 本机项目、文件编辑、diff、终端 | 开源外壳无对应工作区实现 | 我们已有；网页开发预览较完整，原生安卓尚无等价内嵌开发预览 |

## 视觉与交互改造优先级

1. 先统一两端首页、会话、侧栏和输入区：集中输入焦点，减少大卡片和重复标题，保持正文可读、点击目标足够大。借鉴截图的留白和层级，不照搬品牌或 Electron 标签栏。
2. 补齐深浅主题和跟随系统；统一弹层、键盘避让、状态反馈与过渡动效。
3. 打磨既有基本功能：运行时滚动稳定、队列反馈、图片预览保存、代码与公式、窄屏表格。
4. 接入真实 Codex 额度数据，再考虑语音输入与桌面多会话快捷切换。语音对话需要后端能力，不能仅放一个麦克风按钮。

## 代码复用边界

仓库 `src/custom-tabs.js` 创建 webview，`src/main.js` 提供 Electron 窗口、主题、权限和额度桥接，`index.html` 包含额度 UI。聊天主体加载 grok.com，不包含其聊天组件源码；这些 Electron 接口不能直接用于 Compose。

README 和 LICENSE 标为 GPL-2.0，package.json 的 license 却为 ISC，存在标注冲突。直接引入源码前应厘清授权并保留适用声明。本次尚未复制其代码。

权限代码将 permission check、runtime request 和 device permission 全部返回 true。这段不能移植到我们的配对和权限流程中。
