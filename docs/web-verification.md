# 网页开发与验证

## 运行

在 `server/` 执行 `npm install` 和 `npm run dev`，然后打开 `http://127.0.0.1:38457/console`。手机使用电脑的局域网 IP。页面仅连接当前网址的 Gateway，避免跨主机请求和凭据混用。

前端入口为 `public/console.html`、`public/console.css`、`public/console.js`。事件合并、路径和预览地址处理位于 `public/console-core.js`。Markdown 使用 marked 和 DOMPurify，终端使用 xterm.js；这些依赖由 Gateway 本地提供，页面不依赖外部 CDN。

| 范围 | 操作与预期 |

| 连接 | 无凭据可打开页面；错误 Token 提示明确；成功后同步项目和会话 |
| 首页与侧栏 | 标题和输入区居中；首条消息后输入框移到底部；桌面展开侧栏让出主区空间，选择项目和刷新后保持展开；手机为抽屉 |
| 输入工具 | 模型与思考强度使用同一个按钮和弹层，模型支持搜索，强度滑条支持拖动与键盘；“＋”入口可上传图片、文件和视频；文件、终端和预览从侧栏进入 |
| 对话 | 首条消息创建会话；流式 Markdown 聚合；重复文字保留；停止使用当前 turn ID |
| 会话隔离 | 另一页启动的任务不会切走当前会话，也不会混入消息 |
| 审批 | 允许后更新状态，已处理请求不再显示操作按钮 |
| 文件 | 编辑、保存；取消放弃修改后保留草稿；列表与详情请求分别处理 |
| 预览 | Markdown、图片、HTML；HTML 相对资源正常加载；网页预览加载 HTML、CSS、脚本 |
| Git | 中文路径正常显示；单文件和片段操作；非 Git 项目返回明确状态 |
| 终端 | 创建 PTY，运行命令，看到执行结果，停止会话；屏幕缩放更新尺寸 |
| 设置 | 模型选择来自桌面可见列表，Provider 只读；审批和沙盒保存到指定 Codex 配置 |
| 离线 | 输入草稿保留；网络恢复后重新连接 |
| 历史可见性 | 按来源标记过滤内部指令和环境，保留真实提问及用户粘贴的标签示例；旧 Gateway 的上下文包装在客户端兼容过滤 |
| 提示与错误 | warning 默认隐藏，可从会话菜单查看；隐藏提示不拆分流式文字，真实错误在对话及历史中保留详情 |
| 布局 | 1440×960、390×844、360×640；导航、输入区及必要操作不被遮挡 |

运行 `npm run build`、`npm run smoke` 和 `npm run test:web`。浏览器验证使用 Chrome；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定 Chrome 可执行文件。`node scripts/ux-review.mjs after` 在真实 Gateway 上检查桌面、手机、窄屏和横屏布局，不发送模型任务。

测试为每次运行创建临时 `CODEX_MOBILE_CONTROL_HOME` 和 `CODEX_HOME`，不会改动日常 Codex 配置。网页测试使用协议夹具模拟模型回复，网关、文件、Git、终端、浏览器和预览服务均实际运行。`artifacts/web-test-results.json` 记录最近一次网页测试结果，PNG 文件用于检查渲染。

## 当前边界

网页预览通过限时访问地址代理电脑本机服务，支持普通 HTML/CSS/JS、动态 fetch/XHR 请求和 WebSocket。真实 Vite 回归已经验证 POST 请求、HMR 更新及更新后保留输入内容。预览访问仍限定在被选中的本机服务，不向预览页面提供 Gateway 的访问 Token。

依赖独立 HMR 端口、特定路由根路径或同源登录态的复杂应用仍需单独适配。Android 0.4.0 使用原生界面，安装与功能范围见 [原生 Android](native-android.md)；网页预览仍从网页版打开。
