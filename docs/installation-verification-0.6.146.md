## 修复记录

- 停止状态的旧网关返回连接拒绝时，Windows PowerShell 的 stderr 行为曾中断更新。安装器改为捕获原生进程输出及退出码；后台已停止时允许更新，仍有监听但状态无法验证时拒绝更新。最终覆盖安装检查已通过。
- 原生窗口初版底部公网地址框被裁切，增加窗口高度后复查截图并验证二维码解码。
- 网关脚本使用安装实例的数据目录，避免自定义目录测试或部署读取默认机器实例。
- 未配置自己的 Cloudflare 隧道时，守护仅启动本机服务；正常公网出网不固定代理节点。
- 公网允许列表补充目标的独立继续接口，保留方法限制。

此前依赖下载尝试发生 EPERM、ECONNRESET 和离线缓存缺项，未用于最终交付；最终从权威源码目录按 lockfile 核对生产依赖后离线打包。构建与安装测试不重用这些失败结果。
