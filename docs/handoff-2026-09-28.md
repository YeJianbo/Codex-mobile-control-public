## 5. 关键决策与教训（重要，别踩回去）

1. **不要给 `closeDialog` 加 JS 延迟动画**：曾导致"连接后异步初始化（restoreDraft）晚于测试填充输入"的时序竞态（表现为输入框被清空、发送按钮永不启用）。浮层退场动画一律用纯 CSS（`@starting-style`/`allow-discrete`/`overlay` 过渡），不阻塞 `close()`。
2. **`details` 展开不能有过渡**：`::details-content` block-size 过渡会让"点击后立即 isVisible"为零高度窗口。方案：只在收起方向过渡（open 态 `transition: none`）。
3. **连接验证**：ConnectionFlowTest 已迁移到 NativeApp/NativeViewModel；不再为旧测试保留整份 LegacyControlScreen。
4. **高亮器安全边界**：只用 DOM API（createElement/textContent），不拼 HTML；未知语言一律原样输出；超长（>60KB）跳过；`dataset.highlighted` 防重复处理。
5. **列表入场动画护栏**：单帧新增 key > 20（整段历史加载/回放）必须整体跳过，否则整屏闪动。
6. **服务端事件搜索两层结构**：SQLite 直接提取 `$.text` 后 LIKE，JS 端复核正文；搜索候选包含导入的 Codex 历史会话。
7. **并行会话**：2026-09-27 有另一会话在发版（打 tag/冻结/产出 zip）。动 README/artifacts 前先 `git log` 确认基线没变。
