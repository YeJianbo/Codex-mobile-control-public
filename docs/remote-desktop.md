# 内网远程桌面

Android 侧栏的「远程桌面」通过已配对的内网网关连接 Windows，进入时切换横屏并全屏显示，退出时恢复原方向和系统栏。单指点击、拖动和长按分别对应左键、拖动和右键；双指缩放和平移画面；悬浮工具栏可切换滚动模式、输入文字和使用快捷键。离开页面时断开连接。

服务端按需启动 VNC，监听本机随机端口，生成一次性会话密码，并在连接结束后关闭。手机与网关之间使用已有认证及 HTTPS/WSS；公网入口不转发远程桌面接口。当前手机架构支持 arm64-v8a 和 x86_64。Windows 锁屏、UAC 安全桌面及不同设备的手势体验需要在实际环境验证。
