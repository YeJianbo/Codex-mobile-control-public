# ChatGPT、Codex 与 Harness 功能核对

初次核对：2026-10-18；侧聊、桌面工具与授权桥状态更新：2026-10-20。目标是让同一项操作在 Android、Web 和不同执行器上保持一致；模型本身的质量、上游授权、服务容量和原生未开放的接口单独记录。

“已实现”表示已找到对应执行路径，不代表本轮全部实测。“部分”表示入口存在但能力或范围不齐；“缺失”表示本项目还没有对应产品功能。实际测试结果在文末单列。当前不能称为与 ChatGPT、Codex 全功能完全一致。

## 官方核对来源

- [Codex 移动端](https://learn.chatgpt.com/docs/mobile)：远程连接、任务列表、审批、发送指令和检查结果。
- [手机远程开发工作流](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)：工作树、目标、运行中引导、排队、附件和审阅。
- [ChatGPT 功能索引](https://learn.chatgpt.com/docs/features)、[使用方式](https://learn.chatgpt.com/docs/use-chatgpt)、[项目与会话](https://learn.chatgpt.com/docs/projects)：通用对话、Work、项目、文件和工具。
- [Codex 客户端协议](https://developers.openai.com/blog/codex-as-a-platform)：线程、轮次、事件与审批的执行器边界。

## 仍需补齐

### 2026-10-20 Codex 侧栏与侧面板专项核对

本次将“侧边聊天”和浏览器单列，不再用“能打开其他会话”或“有网页链接预览”代表这些能力已完成。以下是官方文档、本机 0.162.0-alpha.17.2 app-server schema 与当前 Android / Web 源码的逐项核对；代码路径存在不等于本轮已做真机验收。

| 功能 | 当前实现与缺口 |
|---|---|
| 新会话、独立会话、指定工作目录 | 已有入口；Android `NativeScreen` / `NativeViewModel`，网关 `SessionManager` |
| 最近会话、历史分页、会话搜索 | 已有；侧栏远程搜索、项目分页与增量更新共用现有接口 |
| 项目展开、分组、显示顺序 | 已读取桌面项目顺序；移动侧栏模块只影响模块顺序，尚无完整的项目拖放与置顶管理 |
| 会话置顶、重命名 | 已有，并接入 Codex 桌面状态 |
| 会话移动到项目或分区 | Codex 已有；其他 Harness 的原生迁移仍未统一 |
| 未读标记、手动未读、阅读后清除 | 已有；没有单独的“全部标为已读”入口 |
| 归档、恢复、已归档管理 | 已有，管理入口在设置；批量能力属于会话管理页 |
