# 0.6.127 /150 与 Gateway 0.6.39

本轮以电脑上已合并的 0.6.126 /149、Gateway 0.6.38 为基线，在隔离源码中合入云端交互审查补丁，并进行真实 Chrome 和 Android 模拟器验证。正式运行服务未更新、未重启；未安装实体手机。

## 修复与复现

| 严重度 | 路径与复现 | 实际问题及结果 |
|---|---|---|
| P2 | 展开、收起处理过程，再在中途反向切换 | 0.6.126 的展开在首个采样点已跳到完整高度；新版使用同一尺寸过渡，展开/收起有中间帧，反向切换恢复正确高度。支持减少动态效果。 |
| P1 | 快速 A→B→A、重连、旧分页或队列请求晚返回 | 请求由当前连接和选择代次持有，旧请求不能释放新加载状态、覆盖新会话或抢走焦点。结构化测试与实际浏览器延迟响应验证通过。 |
| P1 | 历史读取失败，再连点重试 | 首次错误有内联反馈；已知正文保留；同一重试只发一个请求，成功后清除错误和 busy 状态。 |
| P2 | 手动回看、消息持续到来、点击回到最新后滚轮打断 | 单一 RAF 跟随当前目标，键盘/滚轮/触摸中断跟随；后台更新和流式输出保持阅读位置。桌面与移动 Chrome 实测通过。 |
| P2 | 加载更早消息直至分页按钮消失 | 本地复核发现候选补丁先改变控件高度再捕获锚点，造成约 55.75px 偏移；改为先记录旧布局，独立复测偏差 0.25px。基线并没有此回归。 |
| P1 | 云端快照点击导入 | 候选补丁的 disabled 检查与通用按钮封装相冲突，点击不执行；改为独立提交锁，实际导入/取消/重复请求验证通过。 |
| P2 | 导入 200 条可见消息 | 默认 180 条读取遗漏前 20 条；只读快照首次读取扩展至 200。实际浏览器验证第一条及总数。 |
| P1 | AGY 使用询问或未明确权限 | CLI 无逐条审批能力，后端现在明确拒绝并且不创建空任务，不把询问变成自动执行。 |
| P2 | Claude 续聊、重复 assistant 快照 | 续聊保留已选 effort，消息身份去重防止 partial 与重复完整记录二次展示；stdio 审批、取消与失败恢复有专门测试。 |

## 证据与边界

- 电脑上的安装版 Chrome，由 Playwright 自动操作，隔离 HTTP/WS 网关及模拟 Codex 响应：50 个回归组通过，另有桌面/移动动效帧采样和快照异常矩阵。不是人工手机操作。
- Android emulator-5554 的独立包 `com.localcodex.control.remotecheck`：19 个定向测试通过，覆盖面板中途关闭/拖动回弹、快速开关、展开状态、云端只读正文、回执恢复、键盘/菜单及大字号。未清除主应用数据。本轮原生界面源码未另行重写。
- JVM 160/160；Node 209/209；类型检查和 TypeScript 构建通过。Release/lint 完成（0 errors /17 warnings）；准确警告计数与 SHA256 见交付 JSON。
- 隔离 HTTP/WS 会话矩阵 6/6、AGY/Claude 实际 mock 子进程 + WebSocket + SQLite 重载矩阵 6/6；停止失败保留运行状态并允许重试。Windows 测试需要拥有测试子进程终止权限，受限执行环境下 taskkill 失败已明确检测，未误报成功。
- AGY 1.2.14、Claude Code 2.1.224 的已安装 CLI 版本/help 已核对，20 个适配测试通过。真实账户模型连通、真实工具执行未验证；未进行计费模型请求。
- 动效记录为 Chrome CDP 的真实 JPEG 帧与原始时间戳，附可离线播放的 HTML；电脑没有 Playwright 视频编码组件，未安装额外软件。各记录操作时序独立，不能当作严格同步的性能基准。

APK 单独不能替换电脑侧 Web/网关行为，需要用户另行更新配套 Gateway 0.6.39。沿用项目既有本地发行签名，证书与上一版一致；这是可安装的 app release，不是 androidTest APK。更新时保留现有配置、设备授权、数据库和会话。构建和交付未改变这些数据。
