# 0.6.135 / Gateway 0.6.46 验证记录

本轮按用户的新修订完成目标暂停、排队续发、组件圆角、侧栏子代理和回答引用的修改。正常应用版本为 Android 0.6.135 / code158，网关版本为 0.6.46；不部署生产网关、不重启正式服务、不安装实体手机、不调用计费模型。

## 实现

- 目标暂停仅转发 `thread/goal/set`，移除随后的 `turn/interrupt`。Android/Web 在暂停后显示“继续”，当前任务仍可用独立的停止按钮中断。
- 用户手动排队的消息不再被目标暂停状态拦住。空闲时队首提供“发送下一条”；只有存在可引导轮次时才显示“改为引导”，不再误开连接界面。
- 修复完成通知先于启动响应时恢复过时 `activeTurns` 的竞态；迟到的旧轮次完成通知也不会清除新轮次。发送确认带当前状态，两端不会因迟到的用户消息确认重新显示运行中。
- 侧栏的最近、置顶、项目和搜索结果只显示主会话，隐藏嵌套或父会话未加载的子代理。保留主会话内的子代理查看及返回主会话。
- 回答记录中的原问题显示在对应答案上方；多问多答保持配对。桌面历史回答和通过网关提交的同步问题回答都保留引用。普通消息不猜测引用对象。

| Before | After | Why |
| --- | --- | --- |
| 控件分散使用 9、10、11、14、16、20 等圆角 | 控件 12，卡片 18，大弹层和输入容器 28；Android dp / Web px | 同类组件共用尺寸，避免局部覆盖互相冲突 |
| 目标暂停按钮变成“停止当前轮次” | 暂停后显示“继续”，当前任务维持运行 | 目标状态与当前轮次操作分开 |
| 回答只有“已登录，可以检查”等内容 | 原问题引用 + 回答，逐条对应 | 直接看出回答对象 |

圆形按钮、进度条端点等几何形状保留；抽屉边缘继续适配设备窗口圆角。
