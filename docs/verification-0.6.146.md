# Android 0.6.146/code169 / Gateway 0.6.57

本版接入压缩会话日志读取，区分当前上下文与会话累计 Token，修复用量弹窗的系统栏颜色，并为两端切换会话增加有上限的缓存。正式网关已部署；实体手机需覆盖安装同签名新版 APK。

## Token 与压缩日志

- 核对实际运行在 25819 的 `local-console/src/server.mjs`，复用其 `rollout-reader.mjs` 的流式 Zstd 读取、完整帧检查和普通 JSONL 优先规则。手机网关原先只搜索 `.jsonl`，现在同时支持 `.jsonl.zst`；日志不解压写盘，同名副本不重复计数，活动事件沿用原始文件及绝对行号。
- 原来的 1716.9M 是 Codex 日志提供的会话累计快照，并非当前上下文，也没有在手机端重复累加。本版继续取最新快照，分别显示“当前上下文”和“会话累计消耗”。输入缓存计入输入，推理输出计入输出；不把不同统计口径的字段混加。
- 压缩后的统计可能是输入、输出均为零但 total_tokens 非零的上下文估计，该值显示为上下文，不显示为最近一次 API 请求。压缩完成后尚未收到新统计时显示待更新，保留累计消耗。
- 接收 `thread/tokenUsage/updated` 实时快照通知，通知用量面板刷新；与磁盘记录按时间选择，不累加重复快照。普通日志从有界尾部查最新统计，不再为用量解析整个聊天历史。
- 正式网关只读核对返回累计 1,732,568,663、上下文 83,548、上下文上限 380,000、占用约 22%；读数会随当前控制台任务继续变化。此处为一次真实采样，不是固定期望值。本机当前控制台日志仍为普通 JSONL；Zstd、截断帧和压缩后统计由隔离压缩 fixture 验证。

## 会话缓存与弹窗

- Android 按服务器、后端与会话区分缓存；最多 8 个会话、估算内容容量 12 MiB。Web 保留当前页面，非当前页面最多 8 个、估算容量 12 MiB。采用 LRU 淘汰，大页不纳入缓存，不为一个过大页面清空其他缓存。
- 命中缓存后先显示正文、已加载历史和阅读位置，后台核对最新内容；运行状态、队列和审批继续刷新，迟到的旧会话响应不能覆盖当前会话。重新连接清除 Android 会话缓存。
- Web 仅在非当前页面内容变化或页面离开当前视图时计算容量，流式回复不反复扫描其余缓存正文；100 次流式更新的回归检查确认未重新计算非当前历史容量。
- 网关压缩尾部缓存最多 8 个文件，每个最多 4 MiB，环形缓冲避免逐块复制整段尾部。同文件并发读取复用进行中的操作；冷读仍需扫描压缩流，不宣称无解压成本。客户端容量为估算内容大小，并非进程堆内存硬限额。
- 用量弹窗配置自身 Window 的透明系统栏与浅色/深色图标，开启系统栏背景绘制，关闭旧半透明标志和 Android 自带 dim 标志，保留自绘遮罩。Android 30 以上让弹窗覆盖系统栏区域，避免窗口适配留白。父 Activity 的颜色设置保留。
