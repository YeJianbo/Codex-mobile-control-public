## 安装中修复的问题

1. 正在运行的桥接 EXE 被 Windows 锁定：改为生成新的桥接 EXE，保存其路径供未来启动及卸载恢复使用，保留当前桌面进程。
2. 旧计划任务可能在复制阶段重新启动旧守护：升级前先停用属于该安装的旧任务。
3. 后台启动后，安装器等待继承的输出管道 EOF 而未退出：按直接子进程退出结果完成安装，限时排空输出。
4. 本机 Windows PowerShell 无法加载 Get-FileHash，该次退出码 1、复制阶段中断：已恢复后台，并改用 .NET SHA-256 比对相同运行时。最终安装退出码 0。
5. 相同 Node 运行时可能仍被桌面共享占用：内容一致时保留该 EXE。升级会关闭属于同一目录的管理窗口，再打开新版本。

旧程序完整备份位于 `%LOCALAPPDATA%\CodexControl\backups`，安装前敏感配置另存于 `%USERPROFILE%\.codex-mobile-control\installer-backups`。这些备份保留在本机，不进入通用发行 ZIP。
