# Android 0.6.130 / versionCode 153

在0.6.129基础上修复原生会话阅读与切换：用户回看旧消息，切到其他会话再返回时恢复原锚点和像素偏移，保持脱离自动跟随；原来会跳到最新位置。缓存只保留不透明行ID、位置与跟随状态，最多40会话，仅在当前 ViewModel 内存中，不保存消息正文或凭据。

会话消息区域按 threadId 隔离 Compose 生命周期。离开会话时取消该会话的滚动动画和协程，避免“回到最新”中途切换影响另一会话。快速反复切换与重复打开覆盖原生 UI 回归。

修复前后的同一模拟器用合成消息验证：旧版阅读语义位置4000→22187，新版保持原位置。首轮测试误把滚动语义值当作行索引，在操作切换前失败，已记录为测试准备错误；最终复现使用真实可见第8条消息作为准备断言。

该APK只改变原生客户端。电脑网关继续使用已部署0.6.41，无需为本轮修复重新部署或重启网关。公网后端限制、凭据、访问边界保持现有行为。使用独立模拟网关做 Codex / AGY / LAN Claude 的回归；没有真实计费模型调用。

浏览器与原生验证均为用户电脑上的自动化。没有 CUA 手工操作工具；不把静态截图称作手工体验，模拟器结果也不代表实体手机或所有 Android 版本。
