# 图片补丁统一合并：Android 0.6.134/code157，Gateway 0.6.45

## 来源及保留范围

在主工作树 0.6.133/156、server 0.6.44 上逐项应用图片功能补丁，排除其旧版本文件和旧发布说明。交接 ZIP 内 433 个源码文件全部符合清单 SHA256；补丁与未压缩说明也与 ZIP 内一致。没有整树覆盖。

保留主会话/侧栏子代理折叠、子代理完成静默、目标计时与结束提示、紧凑文件差异、AGY 流式完整性、快照只读、回执恢复、分页阅读位置及远程启动功能。

## 合并与修复

- 同一连接、同一图片和尺寸的并行查看共享一次下载/解码。最后一个查看者离开会取消共享任务，HTTP 读取同时取消实际 OkHttp Call。
- 图片输入限制为 32 MiB，对未知 Content-Length 的分块响应也逐块检查；解码尺寸受预览边长约束。
- 连接切换增加图片代际，清理旧请求与缓存。进一步移除界面绕过代际检查的缓存写入，捕获请求所属客户端，并在缓存读写前核对代际。
- 原图读取失败保留缩略图，提供明确重试。切换连接关闭旧图预览；过渡中触摸取消未完成翻页，松手回弹。
- 交接中的目标测试只更新 paused，却始终报告 running。修正模拟接口，使正常暂停同时发出轮次中断确认，保留原产品用例。
- 新增“暂停已保存但中断失败”的用例发现实际客户端错误路径缺少立即刷新。Android 和 Web 均在请求失败后刷新持久状态；尚未停止时显示停止重试，确认停止后显示继续。
- Windows 子进程停止遇到非零 taskkill 结果时，短暂等待该进程及管道真正退出，处理退出竞态；仍未退出则保留失败状态并返回具体终止原因。没有按进程名批量终止或扩大权限。
- 模型目录测试继续使用隔离 CODEX_HOME；生产模型和 effort 合法性校验不变。
