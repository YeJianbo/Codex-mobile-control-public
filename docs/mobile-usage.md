# 手机使用说明

## 平板与 iPhone / iPad

Android 0.6.298 会按窗口实际宽度切换布局：840dp 及以上显示常驻侧栏，顶部按钮可收起；窄屏使用抽屉。横屏和分屏会重新计算布局，对话与弹层保留最大宽度。

iOS / iPadOS 当前交付 [Xcode 工程](../ios/README.md)，也可继续在浏览器使用 Web。套壳使用现有网页配对与会话，iOS 26 原生连接栏采用 Liquid Glass。当前没有经过 Mac 编译的 IPA。

## 助手账号

侧栏新增 DeepSeek Harness 与 Hermes，账号在电脑上各自的官方 CLI 配置。配置入口、安装方式和能力限制见 [助手说明](harnesses.md)。Hermes 的 OpenAI Codex 模型可在模型菜单选择思考强度，需要 Gateway 0.6.100 或更新版本。Android 0.6.304 会在收到电脑端回答后关闭对应问题弹窗，重新连接也会恢复已回答状态。

Android 0.6.302 修复打开助手菜单时的 Hermes 图标崩溃。连接状态显示当前所选助手；其他助手提供“重新检查”入口，Codex 的启动按钮只在选择 Codex 时显示。打开助手菜单会重新读取可用状态与模型；Gateway 0.6.98 可立即更新目录，较早网关仍沿用其原有缓存时间。



## 清理电脑上传附件

Android 0.6.293 与 Gateway 0.6.94 起，在会话右上角菜单打开“存储与缓存”。“电脑上传附件”显示电脑上保留的图片、文件和视频及总占用，可搜索文件名，筛选全部、30 天前或 90 天前的附件；逐项勾选或选择当前列表后，点击清理并确认。Web 的侧栏也有“存储与缓存”入口。

删除是永久删除电脑端上传原件，历史消息中对应的附件将无法再打开。聊天记录、项目文件以及手动另存到手机的文件保留。“手机预览缓存”仍可独立设置上限和清理。

新版客户端在连接、上传及修改草稿时同步附件引用，服务器保存草稿保护状态；发送队列和正在编辑的队列消息也受保护。受保护附件无法勾选，附件上传或电脑有任务运行时暂停清理。保护状态变化后点击刷新。上传原件不自动过期；其他设备应升级客户端并连接一次，让已有草稿引用同步到电脑。

## 完成未读

本机 Codex 会话有新的完成结果时，列表右侧显示蓝色小圆点。电脑端读过后，网关推送状态变化，手机刷新列表并清除圆点；手机打开会话并看到最新结果后，也会清除。停留在旧消息、后台或侧栏遮住会话时不会标为已读。新一轮完成后会重新提示。

蓝点需要 Android 0.6.269 和 Gateway 0.6.87；推送同步和会话筛选需要 Android 0.6.270 和 Gateway 0.6.88。未读来源为电脑端当前唯一的本机账号/主机记录；云端、其他代理或无法确定账号/主机的记录不显示此提示。

Android 0.6.271 起，侧栏搜索右侧的筛选菜单可选“全部”“进行中”“未读”。默认收起，全部模式只显示漏斗形筛选图标；选择其他条件后显示当前名称。选完自动收起，关闭侧栏后再次打开也保持收起。筛选作用于最近会话、置顶会话和展开的项目，会在分页前查找匹配会话。子代理仍归入主会话；子代理运行或未读时，所属主会话会保留。“未读”仅显示有新完成结果的会话，查看最新结果后移出。

## 侧栏模块顺序

长按“项目”“进行中”“置顶会话”或“最近会话”的标题，选择“上移”或“下移”。顺序自动保存在手机本地，重开应用后沿用；移动会跳过当前隐藏的模块，已有折叠状态保持。筛选结果所在模块也可长按调整与项目模块的先后。展开侧栏时会清除会话输入框焦点并收起键盘，侧栏内搜索仍可正常输入。

## 安装与连接

完整发行包附带 Android APK。已有版本可覆盖安装，原绑定保留。也可从电脑管理窗口显示的局域网 HTTPS 地址加 `/downloads/android.apk` 下载。

在手机中选择“连接电脑”→“扫描电脑二维码”，扫描管理窗口的绑定二维码。首次绑定应处于同一局域网；跨网络连接时填写自己的公网地址与授权密码。

0.6.185 起，连接状态与连接电脑页面可点击“连接内网”或“连接公网”，所选路线会保存，断线后仍按该路线重连。点击“恢复自动”重新启用内网优先。公网测试完成 HTTPS、密码、设备认证和实时连接检查后：内网已连接则继续使用内网；未连接则直接连接公网。未配对时只检查公网可达性与密码，需先完成配对。

0.6.193 起，自动选择模式先探测内网，300 毫秒后同时探测已配置的公网；使用先通过检查的路线，取消另一条探测，不再等待两次内网超时。回到前台时，正在使用公网的连接会立即探测内网，可用就自动切回；前台停留期间也会每 30 秒探测一次。切换地址保留当前会话与阅读缓存，仍使用原绑定的证书指纹和设备授权。

## 对话与运行

0.6.195 起，审批卡片会保留“已批准”“已拒绝”或“已失效”，重新打开会话后仍可查看处理结果。“需要你的回答”面板支持选择选项或输入文字，向下拖动标题可收起；点击消息中的问题可重新打开。

0.6.194 起，连接时提前加载当前范围的侧栏；展开侧栏或项目时后台增量更新。仍分批加载，只有点击“加载更多”才增加普通条目数量。正在展开或选中的项目额外保留，不会因排序变化突然消失；服务端已移除的项目会正常移出列表。重新打开应用可先看到上次缓存，运行状态随后刷新。

运行时发送消息会加入队列：收到入队回执前保留输入内容，确认后直接显示队列条目，重连期间也会接收同一电脑的入队回执。Goal 可在会话运行时暂停、继续，不停止当前回复；会话空闲时点击继续，会继续执行目标。

上传附件时，输入区显示当前文件序号和传输进度；未知文件大小时显示已传输字节。数据发完后显示“等待电脑确认”，收到上传结果才完成。点击“取消”停止未完成部分，已上传成功的附件仍可发送；切换会话或电脑连接会取消当前上传批次。上传失败时输入区保留提示，点击“详情”可查看并复制完整错误。

选择已有会话，或选择项目后新建会话。未选择项目的新会话使用 Codex 的默认工作区配置。 最近查看的会话使用有上限的缓存；返回会话会恢复阅读位置，不同电脑分别保存位置。

点击输入栏的模型名称打开紧凑面板，中央显示当前思考强度和模型，下方滑条调整强度；点模型名展开模型列表。左侧闪电切换 Fast，开启为蓝底白色图标，关闭为浅灰底灰色图标。输入栏只在 Fast 开启时显示闪电。进入会话时读取其原设置，点击后保存到该会话。状态读取或保存期间按钮暂不可点；读取失败不会把未知状态当作关闭。

运行中发送的消息进入队列。可以修改待发内容或改为引导；停止操作会等待电脑确认。目标已暂停时，点击目标卡片的“继续”恢复运行，不会额外发送聊天消息。需要换模型时，先选择模型和思考等级，再点“继续”；这些设置会先保存到会话，再恢复目标。

在侧栏或会话右上角菜单打开“定时任务”，可以查看 Codex 已有任务、启用／暂停状态和已同步的下一次运行时间；支持编辑内容、暂停、恢复，以及新建按分钟、小时、天或周间隔运行的任务。新任务默认使用打开面板时的会话，也可点击“指定执行会话”或“更换执行会话”，按名称、路径或 ID 搜索并选择其他 Codex 会话；无需先切换聊天。编辑绑定已有会话的任务时同样可以更换目标，保存后后续触发使用新会话。每次新建会话的 cron 任务保留原执行方式。只有开启“调整运行间隔”才会改变旧任务的原时间规则。任务由电脑上的 Codex 调度，电脑与 Codex 需要保持运行。暂停定时任务会停止后续触发，当前已经开始的会话运行仍使用会话的停止按钮。

定时触发消息显示为一行“定时任务已触发”，内容默认折叠；展开可查看指令，点击“管理”可进入对应任务。已有缓存的 heartbeat 消息也使用此样式，不再显示内部 XML 标签。安卓需升级到 0.6.169，网关需为 0.6.70 或更新版本。

0.6.170 起，断线重试的“正在重新连接”可点开查看原始错误、附加详情及错误类型，支持选择文本和“复制错误详情”。重试期间任务仍保持运行；最终失败会自动展开详情。网页采用相同的展示方式。已保存的新错误详情在会话重载后保留；旧记录只能显示当时已保存的信息。

每轮结束时间位于最终答复的“…”菜单顶部，按手机本地时区显示到秒。没有正文的运行会在该轮末尾显示结束时间。

## 查看过程与结果

长按正文后点“跨段选择”，或在回复“…”菜单、用户消息长按菜单中打开“跨段选择”。选择页包含当前已加载的聊天文字，可拖动选区跨段、跨消息复制，也可全选；更早记录先在聊天中加载。复制内容保留原始 Markdown。

点开图片、图片文件链接或图片附件进入应用内全屏预览，仅使用应用缓存；点击保存按钮才写入相册。边缘滑动可临时唤出系统栏；支持缩放、左右切换和下拉关闭。网页链接直接打开系统默认浏览器。

Gateway 0.6.76 起，只上传文件的历史消息会合并为附件卡片，不再重复显示供模型读取的路径说明。已有会话重新进入后生效，无需重装手机 App。

0.6.174 起，图片预览中的保存按钮会直接存入相册的 Codex 相簿；PDF、Markdown 的保存按钮以及普通文件下载会存入“下载/Codex”，不再选择目录。Android 8–9 第一次保存需要允许存储权限，之后无需反复授权。

在右上角“…”→“存储与缓存”查看占用、设置上限或手动清理。文件缓存默认 1024 MB，可设置为 128–8192 MB；不再按 24 小时清理，超出上限时淘汰最久未使用的预览缓存。当前查看的 PDF 会保留，已经保存到相册和“下载/Codex”的文件不受缓存清理影响。

0.6.183 配合 Gateway 0.6.75，含百分号或井号的文档文件名可正常打开；带行号、查询参数或片段的 Markdown／PDF 链接按文件类型进入阅读器。当前打开文档后从阅读器位置显示，尚不按链接跳转至指定行或标题。

Markdown 阅读器内点击文件链接时，底部显示加载状态；失败可重试或关闭提示。打开 PDF 后关闭预览即可返回原 Markdown。

Markdown 阅读器支持引用式图片，代码中的图片示例按原样显示；长文档按可见区域加载图片。

0.6.172 起，Markdown 阅读器会显示文档中的本地内联图片，相对路径按 Markdown 所在目录解析。图片按比例显示并限制高度，点击可放大；加载失败可点击重试。会话输出文档在已授权项目之外时，需要内网连接及 Gateway 0.6.72 才能读取文档明确引用的目录内图片。单独上传 Markdown 不会同时上传其引用的图片。

每轮操作入口位于回复开头，点击箭头展开；运行结束后默认折叠。子代理从右上角机器人按钮打开。

文件改动卡片显示文件数和已有的新增／删除行数，点击文件可阅读补丁。

回复图片按原比例显示，高度最多 320dp 且不超过半屏。点击图片可缩放、平移、保存；同一组图片可左右切换。PDF 支持连续滚动阅读、缩放与保存原文件；预览按原比例显示，渲染分辨率有内存上限。 打开文件期间切换会话或电脑会取消旧下载，旧文件不会弹回当前页面；需要查看时回到原会话重新打开。

最近查看的会话与图片采用有上限的缓存。切回会话先显示可用缓存，再同步电脑上的最新内容；恢复到前台会立即刷新。

## 连接异常

Gateway 0.6.79 起，共享后端独立运行，手机连接会自动拉起后台，关闭桌面不会停止后台。首次升级前已打开的桌面仍需完全退出一次释放旧会话；若普通启动未接入共享后端，可运行电脑端 `gateway/scripts/start-shared-desktop.ps1`。

手机显示未确认或发送失败时，原消息和附件会保留。重试前会检查上一条发送结果，避免重复提交。

图片加载失败可点击重试。长期断线时，先确认电脑没有休眠、后台服务正常以及所填地址和密码仍有效；重新扫码只用于更换绑定或证书，不用于普通的短暂断网。

发送失败的消息旁可以点 × 移除本地待发记录；提交提示旁的“清除待发”一次移除当前会话的失败记录。× 仅关闭提交提示并记住选择，同一条记录不会因重连重新弹出。已经发送成功的历史不受影响。

Gateway 0.6.84 起，手机向 Codex 发送文件采用桌面端本地附件格式；文件保存在连接的电脑上，模型通过本地工具读取。文字请求和附件分开，刷新历史后保留原下载入口。已有手机版本无需更新 APK。

0.6.198 起，在已有 Codex 会话输入 `/goal 目标内容` 可直接设置并显示目标，无需等待模型把普通消息转成目标；保存失败保留原输入。单独输入 `/goal` 仍打开目标编辑面板。Web 的图片选择、粘贴和拖入统一处理，混合附件上传期间切换会话不会改变附件归属。

0.6.199 起，新会话也可输入 `/goal 目标内容`，直接创建会话并启动目标。输入框中的附件保留待发，设置目标不会发送这些附件；失败可从原输入重试。需要 Gateway 0.6.85。

Windows 0.6.200 中的 Web 控制台会在新目标创建通知丢失后，通过提交回执恢复待发附件；刷新后附件仍归属刚创建的目标会话。Android 沿用 0.6.199。

Gateway 0.6.86 起，新目标启动前的设置失败可以重试，沿用原会话和原请求，不会重复建会话。Web 0.6.201 刷新后也保留该重试信息及待发附件；已发出启动请求但结果未知时仍需先确认会话状态。Android 0.6.199 可使用此网关修复。

Android 0.6.202 起，待发图片和文件随会话草稿保存。切换会话、新建会话或切换助手后，返回原会话可继续编辑；移除或发送后同步清除对应草稿附件。附件记录按连接电脑及证书身份隔离，新建目标时保留的附件跟随目标会话。

0.6.203 起，将待发队列中的消息取回输入框时，即使期间切换会话，文字和附件仍会保存到原会话草稿；返回原会话即可继续编辑。Web 列表刷新失败不影响已经恢复的内容。

0.6.204 起，消息加入待发队列后，已提交的文字和附件会从原会话草稿中移除，期间切换会话也会处理确认；随后输入的不同内容和新附件继续保留。Web 队列列表刷新失败不会让已提交文件留在输入框。

Android 0.6.205 起，同一失败目标再次从输入框发送时，会先确认原提交状态并按回执重试原请求。即使会话已经建立，也沿用原请求的模型、权限和其他设置；结果未知时不会直接激活目标。

Windows 0.6.206 中的 Web 文件编辑按文件顺序处理保存请求，连续 Ctrl+S 保存相同内容会合并。保存期间继续编辑时，会提示提交的版本已保存、后续修改尚未保存。Android 沿用 0.6.205。

Android 0.6.207 修复项目文本文件没有保存入口的问题。修改后可保存回电脑，保存期间的新修改仍显示为未保存。关闭面板或切换文件后返回，会恢复本次客户端运行期间的未保存文字；退出客户端前请正式保存需要保留的修改。

Android 0.6.208 起，改动查询固定发起时的项目，切换项目或重新查询后不再显示旧回包。工具操作失败不会清除聊天的发送中状态。

Android 0.6.209 的终端按电脑和项目分别复用会话，切换回来可查看最近输出并继续输入。命令在电脑确认接收后才清空，失败会保留输入并显示原因；提交期间的新输入也保留。项目终端记录和输入草稿保留于本次客户端运行期间。

Web 新建会话发送首条消息后，可继续输入和添加附件；会话创建完成时，后续草稿和上传中的附件会归入该会话。刷新后从会话列表重新进入，可继续编辑。

Android 0.6.211 起，新建会话发送期间继续输入或添加的附件，也会随新会话保存；返回该会话可继续编辑，原项目的新会话输入框不会重复出现这份草稿。

Android 发送失败时，若编辑区已有后续文字、图片或文件，会继续保留这些新内容；原消息可在失败卡片上点击“重试”。重试只发送原消息，编辑区的新附件仍可继续使用。

Web 新会话首条消息失败时会恢复原附件，刷新并重新进入会话后仍保留。提交结果待确认时不会重发；确认失败后可带原附件重试，成功确认后移除已提交附件。

Web 收到消息确认或发送成功确认后，即使漏掉创建通知，也会进入已创建的会话，并保留等待期间继续输入的草稿与附件。

Web 0.6.281 起，可将纯文字拖入消息输入框，浏览器按原生方式插入，多行内容保留。粘贴实际文件时，图片和普通文件都走附件上传；剪贴内容同时包含纯文字时，保留浏览器原生文字粘贴。文件上传仍按原批次规则处理，拖入内容或粘贴附件不会自动发送消息。

Android 0.6.282 起，发送前可点击文件附件卡片检查内容，沿用会话文件的 PDF、图片、Markdown 或系统打开流程。关闭查看后草稿和附件保留；点卡片内的移除按钮只移除该附件，不打开文件或发送消息。

Android 0.6.283 起，`.pdf` 附件即使由文件提供方标记为通用文件，也会使用应用内 PDF 阅读器；PDF MIME 带参数或大小写不同也能识别。可在发送前检查内容，关闭后继续编辑同一份草稿。

Gateway 0.6.91 起，新上传文件的 MIME 会统一大小写并去除参数，保留 PDF、图片、Markdown 等预览类型。Web 0.6.284 对已有附件也按规范 MIME 判断；无扩展名的 PDF、图片和 Markdown 可在当前页面预览，关闭后草稿与附件保留。未知或非法类型仍提供下载。

Android 0.6.285 起，5MB 以内的 UTF-8 文本附件（TXT、JSON、日志及常见代码文件）可以直接在应用内阅读和选择文字。文本中的 Markdown 或 HTML 标记显示原文；点“保存”才导出到下载/Codex，并使用对应文件类型。关闭阅读器后原草稿及附件保留；较大的普通文本文件仍交给系统应用打开。

0.6.286 起，两端文本预览支持 UTF-8 和带 BOM 的 UTF-16LE / UTF-16BE。Android 导出保留原编码与 BOM；Web 的下载保留原文件字节。Web 无法解码时会说明原因，仍可下载；Android 的附件沿用保存原文件并由系统应用打开的流程。无 BOM 的其他编码不会自动推测，预览仍按原有大小限制处理。

Android 0.6.287 起，超过 5MB 的 Markdown 附件及会话文件保存到下载/Codex 后交给系统应用打开，不占用内置阅读器；普通文件仍有 100MB 下载上限。较小 Markdown 继续提供阅读/源码切换，保存保留编码与 BOM。

Web 0.6.288 起，不超过 5MB 的附件可依据明确的 JSON、XML、YAML、TOML 或 JavaScript MIME 在原页显示原文，即使文件没有扩展名；也支持 Kotlin、Java、Go、Rust、C/C++、SQL、PowerShell 等常见代码扩展名。标记保持字面内容，下载保留原字节，关闭后草稿和附件保留；未知类型与超过大小限制的文本继续下载。

Android 0.6.289 起，上传方没有提供类型或只提供通用二进制类型时，阅读和系统打开会根据文件名使用合适的格式。常见代码文件按文本阅读，保存保留原扩展名和字节，不再被追加 .txt；系统未识别的代码扩展名在下载目录中可能显示为通用文件，请用代码编辑器打开。Markdown 按 Markdown 类型保存，未知文件保留通用二进制类型。明确类型会规范大小写、空白和参数，已有预览大小限制继续生效。

Android / Web 0.6.290 与 Gateway 0.6.92 起，不再额外限制每条消息只能带 8 张图片；选择、发送、历史复用和队列恢复遵循同一规则。每张图片仍需不超过 5MB，这是网关上传限制。普通文件及视频保持每条消息共 8 个的既有上限。手机覆盖安装新版，网页刷新即可使用；后端不支持图片或实际处理达到限制时，会保留消息并显示后端错误。

Android / Web 0.6.301 起，主页顶部不再显示助手名称，中央品牌图标增大。Hermes 与 DeepSeek 使用官方品牌标志。Android「电脑控制台 → 统计」新增两个来源，显示费用状态、订阅包含与参考估算；需要 Gateway 0.6.97 和 Local Console 0.12.3。

Android 0.6.302 起，修复打开助手选择器时 Hermes 图标引起的闪退。连接详情按当前选择的助手显示就绪或不可用状态；切换助手与打开连接详情时重新读取助手目录，Gateway 0.6.98 起支持立即刷新目录。

Android 0.6.303 起，Hermes 模型选择器显示具体模型名，例如 gpt-6.1-sol，调用仍使用原生完整模型 ID。电脑端保存 DeepSeek 模型账户时同时更新手机会话使用的 ACP 配置，已配置的自定义模型会进入原生模型目录；新建 DeepSeek 会话使用保存的模型。覆盖安装 APK 后重新打开模型选择器；旧目录缓存更新后即可看到自定义模型。
