# Android 0.6.144/code167 / Gateway 0.6.55

本轮按用户的两张手机截图修正：科研会话已经停止，但“推进课题”仍出现在进行中并转圈；旧轮次还使队列开放“改为引导”，发送遇到会话连接失效。

## 改动

- Android 和 Web 的进行中列表只根据会话及子代理的实际运行状态生成。目标 active 表示目标未结束；当该会话未运行时，目标栏显示“待继续”，保留目标内容与已用时间，不改写 Codex 的目标数据库。
- 队列读取和引导操作先核对当前轮次状态。已中断的轮次不再因为历史里有开始记录而开放引导。
- 网关会核对自己缓存的轮次；notLoaded 通知和读取结果会清理失效的运行轮次及已加载连接记录。其他客户端的 thread/started 通知不再冒充本网关已经恢复过会话。
- 明确的 thread not found 拒绝发生后，本网关重新恢复会话，再使用相同输入、附件、模型、思考等级、模式与权限重试一次。超时和结果不明的断线不重复提交。
- 恢复事件从全局重放环中淘汰后，持久化的结束状态仍能保护较旧的开始记录。后台状态读取失败或未知时，已跟踪的新运行轮次不会被较早完成记录覆盖。
