# Gateway 0.6.59：公网回复图片 404 修复

2026-10-04 完成，Android 沿用 0.6.146/code169。

## 原因与修改

V2Board 回复中引用的 `user-generation-production.jpg` 在电脑上存在。项目文件和会话输出文件的内网读取均返回 200；公网允许列表拒绝整个会话输出文件入口，手机选择该回退入口时返回 404。

会话输出入口现允许公网 GET PNG、JPEG、GIF、WebP 图片。网关还会核对图片确实出现在指定回复的 Markdown 图片引用中、文件真实路径位于现有授权项目内、大小不超过 20 MiB，并检查文件头。返回真实图片 MIME 及 nosniff。普通文件、写操作、未引用路径、项目外文件和伪装文件不在此范围；不新增项目授权。

## 验证

- Node **298/298**，网关 smoke **39/39**，TypeScript 编译通过。
- 隔离的真实网关请求使用设备证书签名，验证图片成功、项目外图片/伪装图片/替换路径被拒绝。
- 正式网关已部署 **0.6.59**，当前桌面会话进程保留。
- 使用临时签名设备通过真实公网读取截图中的 V2Board 图片：**HTTP 200、image/jpeg、42,688 字节**，与原文件逐字节一致；Pillow 解码为 **1280 × 720**。
- 错误密码与无签名请求为 401；普通文件入口为 404；替换路径为 403。验证结束撤销临时设备。
- 首次实测脚本遗漏配对请求签名，返回 400；补上签名后上述实测通过，不将那次失败作为图片验证结果。

本次不修改 Android，不发送模型任务，不修改 V2Board 项目、生产账号或发布内容。实体手机展示效果由用户点击原图片重试后确认。
